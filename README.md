# PocketCat

Мобильная среда для создания игр на визуальных кирпичиках в духе Pocket Code: проекты и сцены, редактор игровой сцены, цветные категории событий, управления, физики, звука и данных. Интерфейс описан в `ui/main.slint` и управляется из Rust; для Android используется нативный Slint backend. Java и виртуальная машина в логике приложения не используются.

## Запуск

Требуется Rust stable.

```sh
cargo run
```

## Android APK

Workflow **Android APK** собирает debug APK для `arm64-v8a` при запуске вручную или при изменении исходников. Для локальной сборки установите Android SDK/NDK и `cargo-apk`, затем выполните:

```sh
cargo install cargo-apk
rustup target add aarch64-linux-android
cargo apk build --lib --target aarch64-linux-android
```

APK: `target/android-artifacts/debug/apk/`.

## Scene Manager

`src/scene.rs` содержит движковую модель сцен: `StartScene` пересоздаёт состояние из определения проекта, `ResumeScene` восстанавливает сцену из `cached_scenes`; реализованы события «При старте», «При возобновлении» и «Всегда», координаты спрайтов, локальные/глобальные переменные, гравитация, пауза фоновых сцен и `reset_scene_cache`. `SceneServices` — адаптер платформы, через который `OnDeactivate` глушит аудио, закрывает диалог/клавиатуру, отключает сенсоры/касания и приостанавливает кирпичики; реализация Android/iOS подключается в приложении.

Тесты движка: `cargo test`.

Текущий Rust-порт уже включает мобильные экраны сцен и категорий, исполнение переходных кирпичиков сцен и JSON-импорт/экспорт проекта через `PocketCat-project.json`. Это перенос ядра и основных экранов, а не завершённый паритет с оригиналом: инструменты рисования, аудио/видео, частицы, поля ввода, формулы и остальные блоки ещё требуют отдельных Rust-модулей.
